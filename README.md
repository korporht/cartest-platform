# CarTest — 车机语音测试工作台

把车机语音测试散落的工具合并成**一个内核 + 一条可重复、可追溯的流水线**的本地 Windows 桌面工作台。

> **一句话**：一个窗口跑完整链路 —— 选用例表 → 选设备 → 点跑 → 实时进度 → 自动抓日志 → 自动提取判定 → 自动回填 → 出报告。

桌面端应用（免安装 exe）在 [Releases](../../releases) 页面下载。

## 功能总览

| 模块 | 能力 |
|---|---|
| **测试流程** | 批量灌入 · 实时进度 · 暂停/恢复 · 断点续跑 · 从指定序号重灌 · **灌入中停止即刻生效** |
| **语音灌入** | 单句灌入 · 同句循环灌入 · 参数可调（间隔/超时） |
| **日志终端** | Logcat 实时抓取（缓冲区/关键词过滤）· 截图时间戳水印 · 时间戳转换（10/13/16/19 位） |
| **对话还原** | 离线提取：从设备日志还原对话与判定链路，支持流式分片聚合 |
| **日志切割** | 按时间段提取/切割车载日志 |
| **Monkey 压测** | 部署 → 一键流 → 状态监控 → 停止 → 拉取分析 → 报告 |
| **应用与传输** | APK 安装/卸载/强停/包列表/版本查询 · 文件推送与拉取 |
| **屏幕与触控** | 截图 → 点按坐标换算 → 发 tap · 初始化连接（root/remount） |
| **配置中心** | 多平台档案（日志路径/灌入 URI/判定规则按平台隔离）· 配置方案增删改（最多 5 组）· 即时保存 |
| **任务与队列** | 长任务跨页存活 · 设备操作队列（忙则排队）· 全局操作日志抽屉 |

## 快速开始

1. 从 [Releases](../../releases) 下载 `CarTest_vX.Y.Z_win64.zip` 并解压
2. 准备 adb（加入 PATH，`adb version` 可用）
3. 双击 `CarTest.exe`（桌面窗口模式）或命令行 `CarTest.exe --web`（浏览器模式，默认 http://localhost:8560）
4. 连接车机（USB 调试开启），顶栏选中设备即可开始

详细操作见压缩包内《使用说明.md》。

## 注意事项

- exe 请放在**有写权限**的目录（旁边会自动生成 `logs/`、`reports/`、`runs/`）
- 同一台电脑同时只能运行一个实例（单例互斥；`--restart` 可清旧重启）
- 内置平台档案（PLT1/PLT2/PLT3）为**泛化示例值**，接入实际车型时在「配置」页新建方案填写真实值
- PyInstaller 打包的 exe 可能被杀软误报，可加白名单；下载后请核对 Release 附带的 SHA256
